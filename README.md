# Paul – 6 Distinct Landing Page Portfolio

Dieses Repository enthält sechs bewusst unterschiedliche, statische Landingpages für ein GitHub-Portfolio.

## Enthaltene Projekte

1. **FinPilot** – Dark SaaS / Analytics Layout mit Dashboard-Hero, Bento-Grid und Sticky Workflow.
2. **Klarraum** – Helle lokale Service-Seite mit Buchungskarte, Service-Kacheln und Trust-Checkliste.
3. **WildRoute** – Immersive Travel-Seite mit Fullscreen-Hero, editorial Typografie und Routen-Story.
4. **PulseForge** – Dynamische Fitness-Seite mit Split-Screen, Marquee, Tabs und Performance-Optik.
5. **NovaCraft** – Futuristische AI-Agency-Seite mit horizontaler Card-Reihe und Lab-Sektion.
6. **Lumière Table** – Editorial Restaurant-Seite mit Menülisten, Eventbereich und Reservierungsformular.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Lokale WebP-Assets
- Kein Framework
- Kein Build-Step

## Nutzung

Öffne `index.html` direkt im Browser oder hoste das Projekt über GitHub Pages.

```bash
git init
git add .
git commit -m "Initial portfolio landing pages"
git branch -M main
git remote add origin <dein-repo-url>
git push -u origin main
```
